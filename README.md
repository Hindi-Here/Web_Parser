## Web_Parser

Программа для парсинга web страниц. По умолчанию (без настроек) выводит весь контент страницы без учета <style> и <script>, который находится вне тегов (TextContent или InnerText).

Предоставляет функции углубленного парсинга, включая: парсинг по регулярным выражениям и селекторам, замену через Regex.Replace, контроль выводимого контента.

Для парсинга страниц используется библитека AngleSharp, которая работает со статическим HTML кодом. В связи с этим парсинг многих страниц невозможен (Twitch, Youtube, и прочие, где используется динамическая подгрузка данных).

## Функции панели настроек

🔧 **Кнопка вернуться**. Откатывает контент TextBox-вывода на 1 шаг назад (хранит только 1 предыдущее действие);

🔧 **Regex замена**. Состоит из TextBox со строкой регулярного выражения для поиска заменяемых фрагментов и TextBox со значением на которое заменяется контент;

🔧 **Regular парсинг**. Парсит страницу, исходя из строки регулярного выражения. На практике труден в использовании;

🔧 **Selector парсинг**. Парсинг страницы на основе контейнеров и атрибутов. Современных подход к парсингу;

🔧 **CheckBox добавления контента**. Если true (активен), то добавляет новый контент к старому без перезаписи TextBox-вывода;

🔧 **Количество выводимых значений**. Если значение "All", то выведет все совпадения по Selector парсингу, иначе выведет ограниченное число совпадений;

🔧 **Статистические данные**. Просто отражает статистику по текущему TextBox-выводу.
